# Security Policy

## What this repository is

One static page. `README.md` renders at [github.com/mathewmusango](https://github.com/mathewmusango)
and points at the SVG cards and badges beside it — nothing else. There is no application, no
dependency at runtime, no build step in CI that executes repository code, and no secrets. The page is
served by GitHub from these files.

## In scope

- a card, badge or link that fetches from, or points at, somewhere it should not
- anything committed here that should not be public
- a workflow in `.github/` that grants more permission than the job needs

## Reporting

Email **musangomathew@gmail.com** with what you found and how to reproduce it. Please do not open a
public issue for a security report.

I read every report and aim to reply within a few days. There is no bug bounty.
